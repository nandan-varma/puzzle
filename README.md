# Puzzles

A collection of cognitive tests measuring different mental skills — built in 7 days for a job application's take-home project. The tight deadline forced modular, fast-to-write code, which turned out to be a more valuable exercise than the puzzles themselves.

## Puzzles

- **Word Search** (`/analytical`) — find hidden words in a letter grid
- **Memory** (`/memory`) — match pairs of cards
- **Tower of Hanoi** (`/logical`) — classic disk-stacking logic puzzle
- **Whack-a-Mole** (`/speed`) — reaction speed test
- **Ping Pong** (`/pingpong`) — hand-eye coordination test
- **Mystery Mansion** (`/story`) — narrative-driven puzzle

Login and a dashboard track results across sessions, backed by Firebase.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Built with

- [Next.js](https://nextjs.org) (App Router)
- [Firebase](https://firebase.google.com) — auth and stored results
- Tailwind CSS
